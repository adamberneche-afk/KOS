What the System Does

Students receive AI-powered feedback on written work within 1–3 minutes — as many times as they need, any time of day. Teachers define the rubric once. The system enforces it consistently across every student and every draft.

The system runs entirely inside Google Workspace. No third-party vendor. No student data leaves the school. No additional licensing fees beyond our existing Workspace agreement.

Teachers receive only verified, passing submissions. Their grading workload shifts from formative drafts to final review.

Why It Matters

For students: Feedback within minutes, not days. Specific, actionable revisions. No penalty for iterating. Students who previously submitted one draft now submit 2–3.

For teachers: Formative grading burden eliminated for assignments running through the system. Estimated 90+ hours recovered per teacher per year.

For the district: No new vendor contract. No DPA negotiation. No procurement process. Deployed inside existing infrastructure in approximately one hour.

Google Sheets Schema

Data entry structure
📊
Create one Google Sheet with two tabs: "Deployments" and "Outcomes". Share edit access with teachers you onboard. This dashboard reads from data you paste into the "Import Data" panel below — or connect it live via the Apps Script snippet at the bottom of this page.

Tab 1 — Deployments

One row per teacher deployment
ColumnTypeDescription
deployment_idTextUnique ID — e.g. D001, D002. You assign this.
date_deployedDateWhen the system went live for this teacher
teacher_nameTextFull name of the teacher
buildingTextSchool building name
subjectTextSubject area (English, Science, History, etc.)
grade_levelTextGrade(s) taught (9, 10-11, 9-12, etc.)
student_countNumberTotal students using the system
assignments_createdNumberNumber of assignments set up in the system
statusTextActive / Pending / Complete
deployer_notesTextYour notes on the deployment — what went smoothly, what needed adjustment

Tab 2 — Outcomes

Teacher self-reports — one row per teacher per term
ColumnTypeDescription
deployment_idTextLinks to Deployments tab — same ID
report_dateDateWhen the teacher filled this in
termTextAcademic term (e.g. 2025-26 S1)
hours_saved_weeklyNumberEstimated hours per week saved on formative grading
avg_drafts_beforeNumberAverage drafts students submitted before system (estimate)
avg_drafts_afterNumberAverage drafts students submitted with system this term
would_recommendYes/NoWould you recommend this to a colleague?
quoteTextOne sentence you'd want an administrator to read about your experience
challengesTextAnything that was harder than expected or needed support
observationsTextWhat you noticed about student behavior, engagement, or writing quality

How to Connect Live Data

To have this dashboard read live from your Google Sheet, publish the sheet as a CSV and paste the URL into the import field below. Or use the manual JSON import in the Add Entry tab to paste data directly.
// In your Google Sheet: File → Share → Publish to web
// Choose the Deployments tab → CSV format → Publish
// Paste the resulting URL into the Import field in the Add Entry tab
