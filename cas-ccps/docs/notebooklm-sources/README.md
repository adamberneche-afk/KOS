# NotebookLM sources

Clean Markdown conversions of the four confirmed user-guide HTML docs one
directory up (`../12_TeacherQuickStartGuide.html`,
`../TEACHER_REFERENCE_GUIDE.html`, `../STUDENT_QUICK_START.html`,
`../USER_EXPERIENCE_REFERENCE.html`), purpose-built as upload sources for a
NotebookLM "user guide" notebook.

**Why these exist as a separate copy, not just the `.html` files
themselves:** NotebookLM accepts raw `.html` uploads, but these four are
richly self-styled standalone pages (heavy embedded `<style>` blocks, CSS
custom properties, interactive toggle/tab JS) — exactly the shape of HTML
that grounds worse than it should. Stripping that chrome and keeping only
the actual instructional content (headings, numbered steps, callouts,
tables) is a real, measured improvement to retrieval/citation quality, not
just tidiness.

**What's intentionally different from the source `.html`:** only
presentation. No instructional content was added, removed, or reworded
beyond what converting HTML structure (styled callout boxes, step
diagrams, status badges, folder trees, pipeline diagrams) to plain
Markdown equivalents (blockquotes, numbered lists, tables, fenced code
blocks) requires. Interactive-only chrome with no informational content
(the quick-start guide's clickable checklist behavior, the FAQ's
expand/collapse JS, the reference guide's sticky sidebar nav) was dropped
since none of it carries content beyond what's already in the prose.

**Maintenance — these are NOT auto-generated.** There's no build script
wiring these to their `.html` source; each is a one-time hand conversion.
If the corresponding `.html` file changes, the matching `.md` file here
needs to be re-derived by hand (or re-generated by asking Claude to redo
the conversion) — it will silently go stale otherwise. If keeping these in
sync by hand becomes a real burden, the next step would be a small
conversion script under `tools/`, following this repo's existing pattern
for other repo-owned build steps (`tools/gas-lint/`, `tools/clasp-sync/`,
`tools/html-lint/`) — not built yet since four hand-conversions didn't
justify it, but the natural place to look first if this repo revisits it
later.

**Not tracked here on purpose:** this README itself isn't meant to be a
NotebookLM source — only the four `.md` files above it in this directory
are. Keep it that way if anything is added to this folder later.
