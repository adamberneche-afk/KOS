# Unit Cross-Reference Links — Legacy Archive → Marketing Exploration Units

Paste these links directly into each Unit's lesson plan doc in Google Docs. When you paste a Drive link into a Doc, Google auto-converts it into a **smart chip** — a live, clickable reference back to the original folder. Nothing is copied or duplicated; this is a one-way pointer only. The chip always reflects the current state of the source folder, including any new student work added later.

No student-named files are referenced directly — every link below points to the **topic folder** (e.g., "Pricing Strategy Scavenger Hunt"), which itself contains the individual student submission shortcuts. Opening the topic folder is how you'd browse actual student work; the chip just gets you there.
