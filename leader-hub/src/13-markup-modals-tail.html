Quick Setup (do once — ~10 min):
  1. clasp push this project (EmailBridge.gs + Code.gs + Config.gs + Data.gs + SCR.gs + appsscript.json)
  2. Deploy → New deployment → Web App (Execute as: Me, Access: Anyone in your domain)
  3. Project Settings → Script Properties → add OWNER_EMAIL = your own Google account
  4. Open the deployed URL, signed in as that account — you're done, nothing to paste here
