## Decided 11-14/15

- **The Sort choice is not kept across reloads.** It lives in page memory
  for the visit, because no cas-ccps page stores anything in the browser
  (the 2026-10-22 rule). A reload starts at Assigned order.
- **Closed-term cards are hidden** unless the teacher reopened the
  assignment (`TurnInOverrides`) or granted its code.
- **The Competencies tab defaults to the whole year:** ratings don't reset
  each term.

## For an agent session picking this up

The earlier notes still hold. Added 11-09 to 11-15:
- **The Ledger's CourseName column is not the lesson's name** on roster or
  rollout rows: it holds the Canvas course name, and 60 and 29 read it as
  the course. Anything that shows a lesson's name resolves it through
  StudentAssignments (13's `_dashUnitNames_`, 36's `_prLessonTitles_`,
  07's `_tdLessonContext_`), with the column as the fallback. #441 added a
  comment on `LEDGER.COURSE_NAME`.
- **Generated Student Dashboard data:** `13c` (teaching order and every
  competency a lesson names) and `13d` (the Review panel) are generated with
  `--check`, like `13b`; a lesson-data change means running all three
  generators.
- **No browser storage, still:** page state that should survive a reload
  goes to the server or not at all (the Sort menu, 11-14).
- **The Student Dashboard polls only while a card waits** (`getMyWaitingStatus`,
  on the public allowlist, the caller's own cards only). A new waiting state
  belongs in `waitingCards()` and the server's answer, not a new timer.
- **The cycle's timing** (`LEDGER_CYCLE_TIMING`) answers "was it Studio or
  the schedule": read it before changing a cadence.
- **A Drive link or ID in a Markdown doc** fails doc-currency's Check 6 (#440). Name the file instead.
