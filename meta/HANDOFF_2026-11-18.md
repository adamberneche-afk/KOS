## For an agent session picking this up

The earlier notes still hold: 11-17's and 11-15's handoffs, and
[`AGENT_NOTES.md`](./AGENT_NOTES.md). Added 11-17 to 11-18:
- **A competency ID read from a sheet goes through `competencyIdText_`**
  (32): a cell may hold "8177-7" as a date, or that date as text. Any new
  reader of a competency ID column uses it (the Student Dashboard project
  has no 32; its data is clean after the repair, and writers format text).
- **The archive:** superseded docs live in `archive/<school quarter>/` at
  their old paths; search with `node tools/archive/search.js`, file with
  `node tools/archive/file.js` (CLAUDE.md, "The archive").
- **Student-facing text inside a page template** (13, 71b): no apostrophe
  inside a double-quoted string in a template literal (gas-lint's parser
  loses its place), no inline `onclick` calling a function declared in a
  template (gas-lint can't see it; attach handlers in code), and nothing
  stored in the browser (`no-browser-storage.test.js`).
- **Rendering the Student Dashboard:** `buildStudentDashboardHtml_({ demo:
  true })` with a `google.script.run` shim answering
  `getDemoDashboardData` renders the real page in Playwright, for
  screenshots and click-through checks.
- **One branch, one PR at a time:** the session can push only its own
  branch, so a second change waits locally until the open PR merges, then
  is cherry-picked onto the new main.
