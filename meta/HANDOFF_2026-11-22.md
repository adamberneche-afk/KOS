## For an agent session picking this up

The earlier notes still hold (the 11-19 handoff's list, and
[`AGENT_NOTES.md`](./AGENT_NOTES.md)). Added 11-20 to 11-22:
- **`npm run check` before a PR** runs what CI runs, in order; its log hides
  which test failed, so rerun `node --test --test-reporter=tap <files>` and
  grep `not ok`.
- **The size ratchet:** a file listed in `tools/gas-lint/size-budgets.json`
  may not grow. Put new code in a new file (`80b` beside `07`), and make room
  for wiring lines by shortening dated comments, not by raising the number.
- **A new deployed file goes in `project-map.json`** for every project that
  loads it, and every test that loads a file calling into it loads it too
  (gas-lint's `sandbox-scope-gap` names most; a test that builds a page
  through `buildDashboardHtml_` must also load the page's partial files,
  which it can miss: `dashboard-plain-words.test.js` did on #549).
- **A page partial** is an `.html` file in the project's `html` list,
  rendered with `renderPageTemplate_` and passed into the page as a value
  (`warmUpPointsPanel`); its script uses the page's globals (`esc`,
  `_openPanel`).
- **A student-facing number rides on an existing allow-listed call** when it
  can (`getMyWarmUpHistory` carries `points`), rather than a new public
  function in `webapp-public-allow.json`.
- **Tests read a page's scripts with `extractInlineScripts`**
  (`tools/html-lint/check.js`), never their own `<script>` regexp: CodeQL
  flags it.
- **WarmUpRegistry's columns are in `80_WarmUpPoints.js`**, not 00: every
  project that reads the tab loads 80.
- **A Drive doc the code makes on a failed open** leaves every link to the
  old one dead without saying so (`KOS_CAS_SIGNAL`, 11-11).
